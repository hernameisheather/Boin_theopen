📢 카톡/문자 자동 발송 방법

정확히 말씀드리면: 카카오톡 개인 대화를 자동으로 보내는 공식 API는 존재하지 않습니다. 카톡은 개인 프라이버시를 이유로 서드파티 자동화를 막고 있어요.

실용적 대안 3가지:

  1. 알림톡 (카톡 비즈니스) — Aligo, NHN 클라우드, 솔라피 등 — 유료(건당 8~15원), 사업자등록 + 템플릿 승인 필요 (2~5일 소요)
  2. SMS 발송 API — CoolSMS, Aligo — 유료(건당 15~30원), 즉시 사용 가능. 전화번호만 있으면 OK
  3. 수동 복사 — 아래 [전체 메시지 복사] 버튼으로 재시험 대상 학생 명단·메시지를 한 번에 클립보드에 복사 → 카톡 단체방/개인방에 붙여넣기 (0원, 즉시 가능)

💡 관리자님이 직접 카톡을 보내시는 경우 옵션 3이 가장 빠르고 무료입니다. 추후 자동화가 필요하시면 옵션 1·2 도입 시 API 연동 코드 작성해드릴 수 있어요.
